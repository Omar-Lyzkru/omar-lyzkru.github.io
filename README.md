# Omar Aguilar Portfolio

[Live portfolio](https://omar-lyzkru.github.io/) for a University of Houston Computer Science student, graduating May 2028 and seeking Summer 2027 software engineering internships and technical campus roles.

## Selected projects

1. **PermitWatch Houston**: four-person CodeRED Orion team project and Environmental Track Winner. The case study describes Omar’s data integration and React/TypeScript frontend work. [Team repository](https://github.com/Abbas9x/permitwatch-houston).
2. **Job Application Automation Platform**: AI-assisted Node.js/Playwright application, with product requirements, workflow safeguards, and review contribution explained.
3. **C++ Console Raycaster**: tutorial-guided Windows console project, with CMake and portable calculation tests. Its image is a real frame read from the running program (see `assets/raycaster/PROVENANCE.md`).
4. **Persistent Task Tracker**: supporting JavaScript, HTML, and CSS project, with screenshots of the live app (see `assets/tracker/PROVENANCE.md`).

Each project opens a case study in the same cinematic showcase dialog, with a shareable URL: `?project=permitwatch`, `?project=job-automation`, `?project=raycaster`, and `?project=task-tracker`. Any other `project` value shows the ordinary portfolio and leaves the URL unchanged.

The **Technical Toolkit** (`toolkit.js`) links each technology to the projects that verifiably use it, with a short explanation and a source file or commit as evidence. Technologies without a verified project use are left out, and there are no skill ratings. Selecting a technology changes no URL or history; **View case study** opens the same showcase as the project card, and closing it returns focus and scroll to the Toolkit.

The downloadable résumé is an exact copy of Resume 15. Project ownership and implementation context are included in the case studies.

The site uses a dark violet identity (Manrope for the interface, JetBrains Mono for code and technical labels). The sections run in this order: a developer-first homepage that features PermitWatch Houston, an equal-sized two-column project grid, the Technical Toolkit, an About section (a biography beside an `omar.json` card, with no portrait), and a Contact finale lit by a violet horizon rather than a second black hole. The Pause motion control in the header and the operating-system reduced-motion setting share one motion policy. The Job Application Automation card keeps an illustrative character-based cover tinted to the palette; its case study uses a workflow diagram that is labeled as an illustration. The PermitWatch images are screenshots of the actual public team demo (landing page captured October 14, 2026; results view captured October 17, 2026).

GitHub Pages serves the root files directly via `.nojekyll`. For local preview, run `python3 -m http.server 4173` from the repository root. No dependencies or build step are needed.
